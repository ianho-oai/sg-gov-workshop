# Singapore workshop guide

Open index.html to use the workshop guide. The page contains prepared prompts and does not execute them or submit files to ChatGPT.

For the first four tracks, complete step 0: select Gmail or Outlook and check that its email plugin is connected, then follow the setup instructions only if needed. Read Your assignment in its own tab after Setup, then use exercise tabs 1–9 or left/right arrows. Complete setup before the timed 45-minute session. Downloads appear above the task instructions with colour-coded file types and Click to download labels. Upload the two source documents at step 1, the image at step 2, and the baseline Excel workbook at step 4, then the new-data workbook at step 7. Later steps reuse those resources and earlier outputs in the same ChatGPT conversation. Prompts are ready to copy unchanged.

Each of the first four track ZIPs contains five resources: two workplace documents (Word or PDF), an image, a baseline Excel workbook and a new-data workbook for step 7. The site files run this workshop guide; participants never need to edit them. Session positions are stored locally and can be reset. Sidebar feature explanations appear on hover, focus or tap. They are guidance, not working connections to a ChatGPT account.

Advanced API has setup and one open-ended task: use a supplied customer-service database to build an assistant that answers and routes queries, generates visual help cards and supports live voice with GPT-Live. Use a Codex workspace with a server runtime and an approved API project. Its three CSV resources are a knowledge database, routing directory and twelve sample queries covering text, image generation/editing and live voice. Check model access, microphone permissions and usage limits before starting. It does not require an email plugin. The guide never accepts API keys or makes API calls.

The 3D Singapore landmark session contains one copyable Blender prompt. Replace <insert your Singapore location here> with your chosen location before using it in Codex.

Email exercises process new batches and maintain a workflow log. Unchanged input must produce no new drafts. Step 9 adds a recurring watch for new emails or public resources. After pasting the prompt, participants verify task creation, source access, checkpoints and the first result. No automation is activated merely by opening this guide; source and scheduling support must be checked in the participant account. Verify preview availability and rehearse the full 45-minute sequence before the event.

## First-visit walkthrough

A five-step spotlight tour introduces Choose your adventure, Next, resource downloads, the expandable model prompt and Advanced API. It appears once per browser and can be skipped or replayed from How this workshop works. Finishing or skipping restores the original task and progress.
