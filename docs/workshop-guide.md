# Singapore workshop guide

Open index.html to use the workshop guide. The page contains prepared prompts and does not execute them or submit files to ChatGPT.

First use the top-left toggle in ChatGPT to switch to Codex. For the first four tracks, then check that the Gmail plugin is connected, then follow the setup instructions only if needed. Read Your assignment in its own tab after Setup, then use the exercise tabs or left/right arrows. Complete setup before the session. Downloads appear above the task instructions with colour-coded file types and Click to download labels. Upload resources at the step where they appear; later steps reuse them and earlier outputs in the same ChatGPT conversation. Prompts are ready to copy unchanged.

Grant review has four resources: a criteria-discussion transcript, an exercise reference, a current-applicant workbook and a historical-awards workbook. Citizen feedback has five resources. Scam education has interview and programme documents plus a survey workbook. JC Economics has a module/reading guide and two question/feedback workbooks. The site files run this workshop guide; participants never need to edit them. Session positions are stored locally and can be reset. Sidebar feature explanations appear on hover, focus or tap. They are guidance, not working connections to a ChatGPT account.

Advanced API has setup and one build task: create a Meet-the-People Session tool that records a resident’s concern, transcribes it with the Audio API, researches official information with Responses API web search and returns a cited answer and next steps. Its admin view reviews, categorises, summarises and visualises saved interactions. Five CSVs provide 32 source-linked government FAQ examples, 18 agency/service routing entries (including internal triage), ten case-guidance records, fourteen verification scenarios and 36 fictional interactions with agency tags. The FAQ snapshot was researched on 29 September 2026; current rules and personal eligibility need rechecking. Create the participant’s own key through the OpenAI Developers API-key skill setup prompt. The workshop guide itself remains static and makes no API calls.

The 3D Singapore landmark session contains visible tool setup instructions and one copyable prompt. Codex checks for Blender, FFmpeg and ffprobe, downloads missing tools from official sources or trusted package managers, and verifies a small render before the full build. Optional Python packages belong in a project-local environment. Run it at the end because rendering uses significant CPU. Replace <insert your Singapore location here> with your chosen location before using it in Codex.

Citizen feedback has eight tasks: summarise meeting transcripts; generate an annotated idea image; write a costed, prioritised brief; analyse historical severity, recurrence and cost and revise that brief; build a filterable dashboard; send a reviewed senior-director summary; rehearse and schedule daily email summaries; and publish a project status site. The dashboard bonus uses the Responses API to group filtered narratives into sub-topics with source IDs. Configure the API key privately in the participant application’s server environment. There is no separate Visualisation task.

Grant review has seven tasks for a fictional Enterprise Singapore AI grant exercise. Summarise the transcript and propose a rubric; research official guidance and generate the criteria visual; evaluate all 20 applicants and write a recommendation report; analyse 300 past awards; compare the cohorts in the combined dashboard/visualisation; send five personalised exercise acceptance emails; then build the process and funnel site. The current and historical workbooks share submission-stage fields. Only historical awards contain actual outcomes. Freeze the criteria before assessment and keep selection, notification, acceptance and funding as distinct stages. Grant review has no separate automation task.

Scam education has seven tasks: synthesise interviews; brainstorm technical and educational interventions in an image-generated mindmap; write a researched proposal ranked by feasibility, effort and ROI assumptions; analyse the public survey; publish a combined dashboard/visualisation with an optional Responses API filtered-comment summary; draft the director email; and create a daily global trends bulletin automation.

JC Economics has seven tasks: map outcomes and readings into a lesson outline; generate a clustered student-question visual; produce referenced answers and twelve focus plans; analyse department feedback; publish a combined dashboard/visualisation; draft a Head of Department email; and create a weekly world-events email automation for an agreed economics concept and authorised class recipient.

Automation is step 7 for Citizen feedback, Scam education and JC Economics. Participants verify source access, saved schedules, state/duplicate handling and the first result. A prompt in this guide does not activate a task. Publishing and scheduled-email capability must be checked in the participant environment; report unsupported operations honestly. Rehearse the selected sequence before the event.

## First-visit walkthrough

A five-step spotlight tour introduces Choose your adventure, Next, resource downloads, the expandable model prompt and Advanced API. It appears once per browser and can be skipped or replayed from How this workshop works. Finishing or skipping restores the original task and progress.
